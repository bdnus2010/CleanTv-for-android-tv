CleanTv
An Android TV security and cleanup app designed for TV remote navigation.
- Scan installed apps for known malware indicators, proxyware SDKs, and possible cryptocurrency-mining code.
- Look up app hashes, files, and URLs using VirusTotal.
- Review suspicious apps and request uninstallation.
- Clear app caches and review old files before deleting them.
- Use optional root controls to inspect protected locations, disable selected packages, and quarantine known artifacts.
- Export scan reports and update indicator databases.
Proxyware detection references VortexisTV’s IOC Scanner and Flo5k5’s proxyware blocklist.
